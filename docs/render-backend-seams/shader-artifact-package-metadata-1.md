# SHADER-ARTIFACT-PACKAGE-METADATA-1

> Metadata/checker only — no relink, no runtime change, no game. Adds an explicit
> deployable **package manifest** for the SPIR-V pilot set + a tool-free CI gate
> that fails when it drifts from reality.

## What shipped
- **`shaders/spv/spirv_package.json`** (generated by `build_variants.py`) — the
  single declared manifest of the baked SPIR-V package:
  - `schema_version`, `generator`, `source_hash_canonicalization` mode
  - `tools`: `glslangValidator` + `spirv_cross` version strings + `compile_flags`
    (`-G --auto-map-locations`, **not** `--auto-map-bindings`)
  - `runtime`: env gate (`MC2_SHADER_SPIRV=1`, default OFF), required extension
    (`GL_ARB_gl_spirv || GL 4.6`), program-atomic GLSL fallback policy, fatal gate
    (`MC2_SHADER_SPIRV_FATAL`)
  - `pilot_families`: `postprocess`, `mech`
  - `excluded_families`: `shadow_mech` + all non-pilot programs (stay GLSL)
  - `variant_matrix`: per family, each variant's `defines` / `variantId` / per-stage `.spv`
  - `hashes`: `spirv_index_sha256`, `sidecars_sha256`, `source_set_sha256`
    (canonical-JSON content hashes — portable across worktrees/machines)
- **`scripts/check-shader-package.py`** — CI-cheap, tool-free gate; registered in
  `check-contracts.sh` as `shader_package`. Imports `build_variants.package_hashes`
  so hashing stays in lockstep with the generator (no copy-paste drift).

## Validation split (portability vs staleness)
- **Cheap CI gate (`check-shader-package.py`, tool-free):** validates content
  hashes (index / sidecars / source-set), variant matrix vs `pilots.json`, pilot
  families, declared-artifact presence + reflection captured, and **no undeclared
  `.spv`**. All inputs are content-based → portable across worktrees/machines.
- **`build_variants.py --check` (runs the tools):** full package compare INCL the
  recorded `glslangValidator`/`spirv_cross` version strings → catches a stale tool
  version (which the tool-free gate can't see without running the tools).
