## §2 Decisions

### 2.1 Projector library + algorithm — **analytical Ramamoorthi-Hanrahan SH-L2 in pure Python**

Pick: write a small standalone Python script using **numpy + imageio.v3**
(primary) with **OpenEXR/Imath** as a hard-coded fallback if imageio
chokes on the specific EXR variant.

Rationale:
- All deps present (§1.2). No install rabbit-hole.
- Analytical equirect projection is ~50 lines of numpy. No external
  C++ tool to integrate (rules out Filament `cmgen`).
- Ramamoorthi-Hanrahan is the textbook reference; many published
  reference implementations to cross-check against.

Fallback chain if any single reader misbehaves at impl time:
1. `imageio.v3.imread(path)` — primary.
2. `OpenEXR` + `Imath` direct channel read — fallback.
3. `cv2.imread(path, cv2.IMREAD_UNCHANGED)` (`.exr` requires
   `OPENCV_IO_ENABLE_OPENEXR=1` env var on some builds) — last
   resort.

If all three somehow fail at impl time → switch to **bootstrap
hardcoded coefficients** (§2.4) and ship V-IBL-STATIC-1 without the
projector tool. Add a `TODO V-IBL-STATIC-1.5` to land the projector
in a follow-up slice. This keeps the visible improvement on the
critical path independent of the projector toolchain.

### 2.2 Coefficient storage — **generated C++ header**

Pick: `RenderCore/IblShCoeffs.h` containing the 9 vec3 constants as
`constexpr float[9][3]` (or `constexpr float[27]`). The header is
either **hand-written from bootstrap values** OR **auto-generated by
the projector script**; identical shape either way.

Rationale:
- Zero I/O at runtime (no JSON parser pulled into the static-prop
  batcher TU).
- Trivial compile-time include — no asset-load failure modes.
- Mission-keyed coefficients are an explicit anti-goal for
  V-IBL-STATIC-1 (deferred to V-IBL-STATIC-2 / V-IBL-MISSION-1
  per parent plan §5). One sky, one set of constants.
- Generated headers are an established repo pattern (shader-reflect
  goldens, feature table).

Rejected for V1:
- JSON sidecar — defers cleanly to V-IBL-STATIC-2 when per-mission
  HDRI selection actually needs hot-swap.
- Inline static constants in `gos_static_prop_batcher.cpp` —
  rejected because `RenderCore/IblShCoeffs.h` keeps the data in a
  named, greppable, easily-replaced location.

### 2.3 Runtime upload — **9 individual vec3 uniforms (array uniform) per flush**

Pick: shader declares `uniform vec3 u_iblSh[9]; uniform float
u_iblShStrength;`. CPU side calls `glGetUniformLocation` once at
program-link time, then `glUniform3fv(loc_uIblSh, 9, ptr)` +
`glUniform1f(loc_uIblShStrength, ...)` per flush in
`gos_static_prop_batcher.cpp`, mirroring the existing
`ambientV1Strength` pattern (verified at lines 564, 773, 808, 3945,
4806 of that file).

Rationale:
- Mirrors V-AMBIENT-STATIC-1 plumbing exactly (one-for-one with
  `u_ambientV1Strength`). Reviewer load is minimal.
- Vertex stage on AMD = reliable (§1.3).
- No UBO binding-slot allocation. No std140 padding gotchas.
- No new SSBO. No new RenderPassContract entry.

Rejected for V1:
- UBO with `vec3[9]` — requires `vec4[9]` for std140; new binding
  slot allocation; coupling decision (new IblUniforms? extend
  ViewUniforms?). All deferrable.
- Shader-prefix compile-time injection — requires shader recompile
  per coefficient change. Rejected because the env-driven gate is
  not the only place coefficients might need to change at runtime
  in V2.

### 2.4 Bootstrap fallback coefficients

If the projector blocks at impl time, use neutral overcast-sky
coefficients (placeholders; low-magnitude so gate-ON visual is
subtle but visible). Order: `{ L00, L1-1, L10, L11, L2-2, L2-1,
L20, L21, L22 }`. Convention Y-up world, RGB linear.

```cpp
constexpr float kIblShBootstrap[9][3] = {
    { 0.50f, 0.55f, 0.65f }, // L00  average sky+ground
    { 0.10f, 0.12f, 0.18f }, // L1-1 +Y sky tint
    { 0.00f, 0.00f, 0.00f }, // L10
    { 0.00f, 0.00f, 0.00f }, // L11
    { 0.00f, 0.00f, 0.00f }, // L2-2
    { 0.00f, 0.00f, 0.00f }, // L2-1
    { 0.05f, 0.04f, 0.03f }, // L20  pole emphasis
    { 0.00f, 0.00f, 0.00f }, // L21
    { 0.00f, 0.00f, 0.00f }, // L22
};
```

The impl slice MUST comment whether the shipped coefficients are
bootstrap or projector-derived. Shader code path is identical.

## §3 Tool spec (projector — `tools/ibl/project_sh.py`)

Filename: `tools/ibl/project_sh.py` (new directory; mirrors
`tools/mc2texcook/` and `tools/shader_reflect/`).

Inputs (CLI):
- Positional: path to equirectangular EXR
  (`data/hdr/DaySkyHDRI063B_4K.exr`).
- `--out PATH` (optional): if given, writes a generated C++ header
  to PATH; else prints 27 floats (one vec3 per line) to stdout.
- `--samples N` (optional, default = analytical / per-texel): for
  Monte Carlo mode — not the primary path.

Outputs:
- stdout: 9 lines, each `<r> <g> <b>` (space-separated, %.9g).
- file (if `--out`): `RenderCore/IblShCoeffs_generated.h` shape:
  ```cpp
  // Auto-generated by tools/ibl/project_sh.py. Do not edit by hand.
  // Source: data/hdr/DaySkyHDRI063B_4K.exr
  // sha256: <hash of input file>
  constexpr float kIblShFromProjector[9][3] = {
      { 0.123456789f, 0.234567890f, 0.345678901f },
      ...
  };
  ```

Algorithm (analytical Ramamoorthi-Hanrahan over equirect):

1. Load EXR → numpy array `(H, W, 3)` float32 linear radiance.
2. For each texel `(y, x)`:
   - `theta = (y + 0.5) / H * pi`  (polar angle from +Y)
   - `phi   = (x + 0.5) / W * 2*pi - pi`
   - World dir `n = (sin(theta)*cos(phi), cos(theta), sin(theta)*sin(phi))`
   - Solid angle weight `dω = (pi / H) * (2*pi / W) * sin(theta)`
   - SH basis (L=0..2): 9 values per Ramamoorthi-Hanrahan 2001.
   - Accumulate: `C_i += radiance(y,x) * Y_i(n) * dω`  (vectorized).
3. Apply the standard convolution factors (cosine-lobe kernel) if
   the consumer is doing irradiance-style ambient. For
   V-IBL-STATIC-1 we want **irradiance** (cosine-weighted integral)
   not raw radiance — multiply each band by:
   - L=0: π
   - L=1: 2π/3
   - L=2: π/4
4. Emit 27 floats.

Dependencies: numpy + imageio.v3 (primary). Both verified present
(§1.2).

Self-contained: ≤ 100 lines of Python. No project imports.

### 3.1 Cross-check

Optional: cross-project with Filament `cmgen --sh=3` if available;
RMS < 1e-2 across 27 floats (Filament uses different basis
ordering — convert indexing carefully).

Mandatory: `--self-test` mode projects synthetic uniform sky
(radiance=1.0) and asserts `C[0] = 1/(2*sqrt(pi))`,
`C[1..8] = 0`. Validates basis math without any external
reference.

#### §4.1 Axis-convention notes (CRITICAL)

V-AMBIENT-STATIC-1 (`19e85517`, `static_prop.vert:271`) uses
`worldNormal.y` as up-axis in the hemisphere lerp — **same Y-up
world convention applies here**. The projector (§3) MUST produce
coefficients in the same basis.

HDRI skybox shader (`hdri_skybox.frag:30-33`) samples equirect via
`atan(z,x)` azimuth + `asin(y)` elevation — also Y-up world. The
projector must consume the EXR with the same UV→direction mapping
as the runtime skybox to keep IBL ambient angularly aligned.

Impl precision:
- Projector dir `(x,y,z) = (sin θ cos φ, cos θ, sin θ sin φ)`
  with θ polar from +Y. Matches skybox decoding.
- Shader `worldNormal` MUST be the same world normal
  V-AMBIENT-STATIC-1 uses — no extra swap.
- Wrong-space symptom: ambient band rotated 90° on surfaces —
  caught immediately by gate-ON eyeball.

Failure-mode precedent: [[gpu-particle-age-zero-curve-trap]] (B1
particles, projection correct but input was wrong-space).

## §5 Validation strategy

### 5.1 Default-OFF byte-identical proof

Env unset/=0 → `s_staticPropIblV1Enabled=false` → upload sets
`u_iblShStrength=0.0` → shader `if (u_iblShStrength > 0.0)` branch
not taken; `eval_sh_l2` is dead code. Stronger than the
multiply-by-zero gate V-AMBIENT-STATIC-1 ships. Tier1 5/5 PASS env
unset; pixel-diff vs pre-slice baseline = 0 bytes.

### 5.2 Kill-switch parity

`MC2_STATIC_PROP_IBL_V1=0` ≡ unset. Capture both, diff.

### 5.3 Gate-ON visible delta

`=1` → strength=1.0 → SH ambient tinted by normal. Use
V-MATERIAL-DEBUG-1 to A/B inspect ambient channel.

### 5.4 Object-ID buffer preservation

IBL path MUST NOT short-circuit V-MATERIAL-DEBUG-1's gbuffer
object-ID write. Tier1 + inspector probes it.

### 5.5 Shader-reflect drift

Expected — defer to SHADER-REFLECT-HYGIENE-4 (Task 10). Smoke
gate ignores it; CI may flag.

### 5.6 AMD vert uniform-array sanity probe

If gate-ON looks identical to gate-OFF, upload sentinel
coefficients (`u_iblSh[0] = (1,0,0)`, rest zero) and check for
red tint. Mirrors F1-3C matrix-diff parity probe.

  V-IBL-STATIC-1.5 follow-up.

  state. Diagnose before any further work.

  modified → STOP, revert, restart.
- Slice exceeds 500 lines diff → split.
